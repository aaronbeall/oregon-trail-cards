# Playback map markers

Generated with the built-in image generation tool, using `assets/progress-wagon.webp` as the style/scale reference. Each icon was a separate generation with a genuinely transparent background; all four preserve alpha and render in the same 54 × 42 px map marker box (46 × 36 px on phones).

- Fort: `assets/map-marker-fort.png`
- Town: `assets/map-marker-town.png`
- Stopped wagon: `assets/map-marker-stopped.png`
- Lost journey: `assets/map-marker-lost.png`

## Shared prompt

> Use case: historical-scene. Asset type: tiny illustrated map marker for a retro Oregon Trail game. The attached wagon is a STYLE AND SCALE REFERENCE ONLY. Create one isolated, centered, horizontally composed icon on genuinely transparent background. Match its distressed hand-inked 19th century woodcut / worn screen-print look: cream, muted ochre, olive, sepia outlines, very restrained colors. Large bold silhouette readable at 54 by 42 CSS pixels, not a detailed scene. Object fills 80% of frame width and about 65% height; ample transparent margin; horizontal baseline; no frame, no circle, no lettering or numbers, no landscape, no shadow blob, no modern gradients.

## Subject prompts

Each subject below was appended to the shared prompt as “Primary request”.

**Fort**

> A compact frontier FORT: timber palisade gate with two short square watchtowers, dark wood gate in the middle; unmistakable fortified silhouette.

**Town**

> A compact frontier TOWN: three clustered wooden false-front buildings, central taller storefront and one small chimney, varied rooflines; a welcoming ochre and cream silhouette distinctly different from a fort; no fence.

**Stopped wagon**

> A BROKEN-DOWN covered WAGON seen in the same side view as the reference, front tow tongue pointing right, detached broken wheel lying beside tilted wagon, sagging axle; clearly immobile but not destroyed. Match the reference wagon size and shape.

**Lost journey**

> A LOST JOURNEY covered WAGON: abandoned and damaged, torn drooping canvas, slumped wagon body, broken spokes, a small leaning plain wooden grave cross alongside. Sad finality, muted gray olive/sepia with tiny terracotta accent. Unmistakably distinct from a repairable broken-down wagon. Face right.

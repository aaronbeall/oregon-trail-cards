# Outcome emblems

Generated with the built-in image generation tool, using `assets/landscape.webp` as the style reference. Transparent generated images were encoded as WebP without compositing or recoloring.

- `assets/outcome-success.webp`: sage check mark.
- `assets/outcome-failure.webp`: terracotta X.

## Success prompt

Use case: stylized-concept. Create ONE small game outcome emblem: a bold clear CHECK MARK for successful arrival, printed in muted dark sage green with an irregular thin cream printed edge, on a genuinely transparent background. Style reference attached is STYLE ONLY: weathered flat lithograph / woodcut ink, rubbed rough edges, visible paper-like ink grain and tiny distressed missing ink flecks. The symbol must read immediately at 36 pixels. Simple two-stroke check silhouette, no surrounding circle, no badge, no scene, no words, no letters, no gloss, no 3D, no drop shadow. Centered square composition, symbol occupies 80% of frame. The texture should feel like stamped ink on the game's antique map, imperfect and handmade, not a clean vector icon. Preserve transparency around and within distressed gaps.

## Failure prompt

Use case: stylized-concept. Create ONE small game outcome emblem: a bold X for a failed journey, printed in muted warm terracotta / rusty brown with an irregular thin cream printed edge, on a genuinely transparent background. Style reference attached is STYLE ONLY: weathered flat lithograph / woodcut ink, rubbed rough edges, visible paper-like ink grain and tiny distressed missing ink flecks. The symbol must read immediately at 36 pixels. Two hand-cut diagonal strokes form a clear X. No surrounding circle, no badge, no scene, no words, no other letters, no gloss, no 3D, no drop shadow. Centered square composition, symbol occupies 80% of frame. The texture should feel like stamped ink on the game's antique map, imperfect and handmade, not a clean vector icon. Preserve transparency around and within distressed gaps. Match a sage check mark's visual weight as its warm terracotta counterpart.
